# 자원거점 실제 유저 쟁탈 V2

V2는 V1 상태머신에 서버 자동 진행과 재접속 복구를 추가한다.

- **선택 타임아웃**: 30초 선택창이 끝났을 때 점령자의 활성 게임 세션이 없으면 포기로 판정하고 도전자가 승계한다. 세션이 살아 있으면 자동 방어로 전투를 시작한다.
- **행동 타임아웃**: 개입전의 매 행동에는 30초 제한이 있다. 현재 행동자가 제한을 넘기면 상대가 승리한다. 행동 번호가 증가할 때마다 서버가 새 종료시각을 기록한다.
- **대기열 승계**: 개입전 해결 뒤 남은 점령 시간이 있으면 `requested_at ASC, request_id ASC` 순으로 다음 요청을 선발한다. 원정이 끝났거나 위치가 달라진 요청은 `EXPEDITION_INACTIVE`로 제거하고, 새 점령자 본인의 요청은 완료 처리한다.
- **기회 기반 진행**: 로그인 사용자의 5초 주기 진행 RPC와 Realtime 갱신이 만료 상태를 서버 트랜잭션에서 전진시킨다. 같은 슬롯은 advisory lock과 행 잠금으로 한 번만 처리된다.
- **재접속 복구**: 다시 접속한 양측은 현재 거점, 개입전, 행동 종료시각과 nonce를 서버에서 재조회하며 클라이언트 로컬 타이머를 신뢰하지 않는다.
