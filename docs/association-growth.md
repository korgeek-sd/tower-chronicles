# 원정단 성장·상점 구현 기준

기존 온라인 원정단의 가입·신청·단원·채팅·점령전 기능을 유지하고, 기부와 공헌도 상점을 연결한다.

- 실버 10,000당 경험치·공헌도 100, 골드 100당 각각 200. 개인별 한국 시간 일일 한도 실버 50,000 / 골드 1,000. 원정단 이동으로 한도를 초기화하지 않는다.
- 경험치는 조직 성장, 공헌도는 개인의 원정단별 상점 잔액이다. 탈퇴 시 기존 잔액을 다른 원정단으로 이전하지 않는다.
- 레벨 누적 경험치: 0 / 1,000 / 5,000 / 15,000 / 30,000 / 60,000 / 120,000 / 250,000 / 500,000 / 1,000,000. Lv10 최대.
- 일일: 강화석 1개(100, 5회), 상급 포션 1개(200, 3회), 실버 10,000(500, 1회), 직능 뽑기권 5개(1,000, 1회, Lv2).
- 주간: 직능 뽑기권 30개(5,000, 1회), 희귀 장비 1개(5,000, 1회, Lv5), 강화석 100개(3,000, 3회), 골드 100(3,000, 1회), 상급 포션 10개(1,000, 3회). 주간 상점 Lv3.
- 리셋: 일일 00:00 KST, 주간 월요일 00:00 KST. 구매 기록을 기간별 조회하며 파괴적 초기화를 하지 않는다.
- 미확정 상자 지급량은 위의 초기값으로 명시한다. 희귀 장비 상자는 기존 공통 9종에서 희귀 +0 장비를 균등 추첨한다.
- 직능권은 서버 보관, 1회/10회 사용, 권당 결과 1개. 기존 골드 등록은 유지한다.
- 칭호·강화석 등급·전설 강화 재료·탐사 티켓·감정권·장기 상품을 추가하지 않는다. 신규 버프나 임무는 이번 확정 범위가 아니다.
- 모든 차감·지급·제한 검사는 DB 트랜잭션에서 실행. 세션 검증, 행 잠금, 요청 UUID 재실행 방지, 서버 저장본 반환.

## 실행 순서

1. 기부 환산·한국 시간 리셋·레벨 경계 테스트와 공통 표시 규칙 구현.
2. 기존 기반 테이블 위에 서버 RPC 구현. 하나의 공헌도 테이블을 사용하고 상점표 수정.
3. 본부 성장·기부와 페이지형 일일/주간 상점 연결. 직능 기록실에 권 사용 추가.
4. 롤백 SQL로 실제 차감·지급·재요청·한도·권 사용·비회원 접근 검사. 전체 테스트 및 빌드.
5. DB 마이그레이션 적용, GitHub 커밋·푸시 및 Pages 상태 확인.
