# A등급 직업 스킬 설계

확정일: 2026-10-06
상태: 사용자 승인 설계

## 목표

A등급 12종 직업에 기본공격 없는 전투 구조를 전제로 액티브 스킬 3개씩, 총 36개를 구현한다.

## 공통 전투 규칙

- 기본공격은 사용하지 않는다. `ACTION_IS_BASIC_ATTACK` 의존 조건도 추가하지 않는다.
- 각 직업은 액티브 스킬 3개만으로 턴을 굴린다.
- 전투 자원은 0에서 시작하고 최대 4칸을 사용한다.
- 1번 스킬은 항상 사용할 수 있는 생성기다. 자원 +1, 쿨다운 0.
- 2번 스킬은 직업 정체성을 드러내는 중간기다. 자원 소모 없음.
- 3번 스킬은 자원 3을 소모하는 강한 마무리기다.
- 신규 전투 메커니즘은 만들지 않는다. 현재 엔진이 지원하는 `DIRECT_ATTACK`, `APPLY_EFFECT`, `REMOVE_EFFECT_TAG`, `CLEANSE`, `DISPEL`, `HEAL_PERCENT`, `HEAL_FLAT`, `SELF_HP_COST_PERCENT`, `CHANGE_RESOURCE`, `SET_FLAG`만 액티브 액션으로 사용한다.
- 조건부 피해에는 현재 지원되는 HP 비율, 대상 효과 보유, 자원 소모량 등의 조건만 사용한다.
- 기존 효과 정의인 `bleed`, `weaken`, `attack_up`, `defense_up`, `regen`, `b_attack_25`, `b_guard_15`, `b_guard_30`을 재사용한다.

## 구현 범위

1. `src/game/jobs/aDefinitions.ts`에 A등급 12종 전투 정의를 추가한다.
2. `catalog.ts`에서 A등급 12종을 `COMBAT_READY`로 등록하고 각 스킬 3개를 연결한다.
3. 현재 클라이언트 전투 엔진에서 36개 스킬이 실제로 동작하는지 테스트를 추가한다.
4. 서버 전투 카탈로그에도 동일한 A등급 정의를 반영한다. 클라이언트와 서버 수치가 달라지지 않도록 생성/동기화 경로를 사용한다.
5. 기본공격 전용 조건이나 자원 획득 경로를 A등급 스킬에 추가하지 않는다.

## 테스트 기준

- A등급 12종 모두 `COMBAT_READY`다.
- 각 직업은 정확히 3개 액티브 스킬을 가진다.
- 모든 1번 스킬은 `GENERATOR +1`, 쿨다운 0이다.
- 모든 3번 스킬은 자원 3을 소비한다.
- 등록되지 않은 효과 ID나 액티브 액션 종류를 사용하지 않는다.
- 기본공격 조건을 사용하는 A등급 패시브/스킬이 없다.
- 주요 조건부 피해, 관통, 회복, 자해, 정화 효과를 각각 실제 전투 테스트로 검증한다.
- 서버 카탈로그의 A등급 스킬 ID·수치가 클라이언트 정의와 일치한다.

## 제외 범위

- 이번 단계에서는 A등급 스킬 이미지 36종을 제작하지 않는다.
- 새로운 상태이상이나 전투 자원 종류를 만들지 않는다.
- SR/SSR 직업 스킬은 변경하지 않는다.
