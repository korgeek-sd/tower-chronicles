# 외형 카탈로그 1차 구축 (2026-10-11)

## 현재 구현 범위

- 기존 `Cosmetics` 저장 데이터 구조와 `selectAppearance` / `registerAppearance` 연동을 그대로 사용한다. 데이터 마이그레이션은 필요하지 않다.
- 기존 기본 모험가 외형 1종은 유지하고, **신규 수집용 외형 40종**을 추가한다. 등급은 **C / B / A / SR / SSR**이며 각 등급 8개씩이다.
- 8개 테마 도감은 각 5종씩 구성하며, 전 등급이 1종씩 포함된다. 테마는 잿빛 외곽, 녹관 성역, 붉은 송곳니, 폐허의 기록, 깊은 심연, 거꾸로 선 제단, 몰락한 도시, 귀환의 길이다.
- `src/game/data/cosmetics.ts`에 콘텐츠 ID, 이름, 설명, 소속 도감, 제안 능력치, 등급, 에셋 준비 상태를 선언한다. 기존 ID `default`는 불변이다.
- 거점 `외형 · 칭호`에 해당하는 메뉴를 `외형 도감`으로 정리한다. 외형 목록 등급 필터 / 수집 도감 / 기존 칭호 탭으로 나누고, 보유/미보유/적용 중 표시, 현재 수집 개수, 도감 채움 정도와 예정 능력치를 제공한다.
- 새 외형에는 아직 실제 이미지 파일을 할당하지 않았다 (`artStatus: 'pending'`). 직업 에셋을 임시로 도용하지 않는다.
- 미보유·이미지 미완성 외형은 선택을 차단하며, 아이템/보유 내역을 자동 지급하거나 뽑기를 실행하지 않는다.

## 수치 (추후 밸런스 대상이며 실제 전투에 적용되지 않음)

| 등급 | 종수 | 외형 획득 제안 보너스 |
|---|---:|---:|
| C | 8 | 테마에 따른 HP/공격/방어 +1% |
| B | 8 | +2% |
| A | 8 | +3% |
| SR | 8 | +4% |
| SSR | 8 | +5% |

도감 세트 완성 제안 보너스는 각 세트에 설정된 HP/공격/방어 +1%다. **전체 외형 보유 능력치의 중첩 방식, 단일 외형 적용 방식, PvP/PvE 적용 범위, 확률, 천장 및 골드 가격은 아직 확정/구현하지 않았다.** 표시하는 수치는 구조와 UI 검토용이며 서버 전투 능력치는 현재 그대로다.

## 보존 규칙

1. 기본 모험가 선택 및 이전 저장 데이터는 유지한다.
2. `imagePath`는 신규 외형에 한해 선택적이며, 누락된 이미지의 캐릭터 렌더링은 기본 아트로 폴백한다. 새로운 외형이 존재한다는 이유만으로 다른 직업의 이미지를 변경하지 않는다.
3. 외형 목록에 있어도 획득·등록되지는 않는다. 뽑기/재화 차감은 서버 RPC 연결 전까지 비활성 상태다.
4. 도감 완성도는 `unlockedAppearanceIds`만으로 계산하며, 중복 아이템 수량은 완료 조건에 포함하지 않는다.
5. `CosmeticsCatalog` 인터페이스는 기존 테스트의 appearance/title fixture와 호환되고 기존 플레이어 저장 필드를 추가하거나 제거하지 않는다.

## 다음 단계

1. 각 외형의 아트 40종을 동일한 비율·컬러 규칙으로 제작하고 `imagePath` / `artStatus`를 갱신한다.
2. 골드 외형 뽑기 서버 RPC, 재화 원자적 차감 및 중복 획득 기록을 설계한다.
3. 외형 능력치·도감 수집 보너스의 수치 및 중첩 정책을 최종 확정하고 서버 전투/스탯에 연결한다.
4. 전투 화면의 직업 아트 우선 렌더링을 개선해 실제 선택된 외형으로 전환한다.
