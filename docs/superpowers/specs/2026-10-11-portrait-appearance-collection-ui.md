# 리니지식 외형 컬렉션 세로형 UI (2026-10-11)

## 확정한 레이아웃

참고: 사용자가 확정한 첫 번째 **세로형 외형 컬렉션 이미지 시안**. 실제 런타임에는 별도의 정적 스크린샷을 넣지 않고 React/CSS로 재현한다.

- 상단: 기존 게임과 같은 다크 판타지 금속·황동 UI, 외형 수집 진행도, `도감 세트 / 외형 목록 / 칭호` 탭.
- 그 아래: 전체/일반/고급/희귀/영웅/전설 필터, 컬렉션/필요 외형 이름 검색, 진행도·보상 정렬.
- 중앙: 길게 탐색할 수 있는 독립 스크롤 컬렉션 목록. 각 행은 컬렉션 명, 고정 능력치 제안 보상, 2~5개 외형 아이콘과 실제 소유 수량을 보여준다.
- 하단: 선택 컬렉션 전용 상세 영역과 필수 외형 카드, 소유/미소유 표시 및 추적·관련 컬렉션·외형 확인 동작.
- 큰 페이지 전체 스크롤 없이 중앙 목록만 스크롤되고 상세 영역은 화면에 유지된다.

## 데이터 모델

- `src/game/data/appearanceSets.ts`: 기본 40개 기존 외형 ID로 65개의 **중복 참여 가능한 조합**을 제공한다.
- 샘플: `잿빛의 생존자들` = 기존 외형 #1, #3, #13을 소유하면 `최대 HP +100` 제안 보상.
- 조합의 결과 보상은 `hp / attack / defense`의 **고정 수치**이며 %, 중복 등록, 아이템 차감이 아니다.
- 수집 여부는 실제 `game.cosmetics.unlockedAppearanceIds` 기반. 컬렉션 완료 계산은 순수 함수이며 외형 아이템을 소모하지 않는다.
- 8개 기존 테마 도감 정보와 40개 캐릭터 외형 카탈로그를 삭제하지 않는다. 원본 데이터·플레이어 세이브의 호환성을 유지한다.

## 구현 제한

- **컬렉션 능력치는 아직 전투에 적용되지 않는다.** UI에서 계획된 보상이라는 점을 명시한다.
- 골드 소모형 외형 뽑기·수집 확정 서버 RPC는 구현하지 않는다.
- 외형 전용 아트는 아직 40종을 제작하지 않았으므로 실제 직업 이미지나 외형 이미지를 허위로 섞지 않는다. 전용 에셋이 없는 슬롯은 등급별 문장 아이콘을 사용한다.
- 추적/즐겨찾기는 화면 내 탐색용 React 로컬 UI 상태다. 데이터베이스나 저장 데이터를 변경하지 않는다.
- 기존 기본 외형 적용, 원정 중 제한, 칭호 메뉴를 유지한다.
