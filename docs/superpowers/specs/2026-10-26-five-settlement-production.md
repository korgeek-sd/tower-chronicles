# 도시 1개·마을 4개 주간 생산 운영 규칙

- 합의일: 2026-10-26 (Asia/Seoul)
- 상태: 설계 합의 기록. 이 문서 커밋은 런타임 구현·DB 마이그레이션 적용·게임 배포 완료를 뜻하지 않는다.
- 범위: 거점 수, 주간 마을 유형, 도시 생산량과 이용 권한, 일일 초기화, 제작 장소.
- 기존 생활·제작 문서와 충돌하는 아래 항목은 이 문서를 이후 구현의 기준으로 삼는다. 다른 전투·성장·점령전 규칙은 변경하지 않는다.

## 1. 거점 구성

- 중앙 도시 노바르 1개와 마을 4개, 총 5개 거점으로 축소한다.
- 네 마을의 농업·약초 유형은 영구 고정하지 않는다.
- 마을 이름과 기존 거점 ID의 통합·이전 매핑은 이번 합의에서 확정하지 않았다.

## 2. 점령자의 주간 마을 유형 선택

- 각 마을의 점령 길드는 해당 주의 마을 유형을 농업 또는 약초 중 하나로 선택한다.
- 농업을 선택한 마을에서는 작물을 재배·수확하고, 약초를 선택한 마을에서는 약초를 채집한다.
- 이 선택은 개별 작물·약초 품목 선택이 아니라 마을 생산 분야 자체의 선택이다.
- 네 마을 모두 같은 유형을 선택할 수 있다. 전체 농업·약초 마을 수를 강제로 맞추지 않는다.
- 선택한 유형은 해당 주에 적용하며, 생산 가능량의 일일 초기화와 주간 유형 선택은 별개다.
- 유형 선택의 구체적인 마감 시각·권한 직책·미선택 기본값과 전환 중인 작업 처리는 구현 전 별도로 확정한다.

## 3. 도시의 생산량

- 노바르는 농업과 약초 두 분야를 항상 제공한다.
- 마을 한 곳의 해당 분야 일일 생산 가능량을 V라고 할 때 도시의 분야별 생산 가능량은 V / 2이다.
- 각 분야의 도시 생산 가능량 중 절반은 공용, 나머지 절반은 도시 점령 길드원 전용이다.
- 따라서 분야별 도시 공용량은 V / 4, 전용량은 V / 4이다.
- 농업과 약초의 생산량·공용량·전용량은 각각 독립적으로 계산하고 차감한다.
- 도시의 길드원 전용 배분 규칙을 마을에 자동으로 확대하지 않는다.

예시: 마을 한 곳의 해당 분야 일일 생산량이 20단위일 때의 비율 설명이다. 20단위 자체를 실제 운영 수치로 확정하지 않는다.

| 도시 분야 | 전체 | 공용 | 점령 길드원 전용 |
| --- | ---: | ---: | ---: |
| 농업 | 10 | 5 | 5 |
| 약초 | 10 | 5 | 5 |

생산량 제한에 관한 합의이며, 신규 수확량 보너스나 제작량 보너스를 추가하는 결정은 아니다. 실제 기준 생산량과 정수 나눗셈 처리는 후속 구현에서 명시한다.

## 4. 도시 생산량 차감 우선순위

| 이용자 | 차감 순서 |
| --- | --- |
| 현재 도시 점령 길드원 | 같은 분야의 전용량을 먼저 차감하고, 부족한 수량은 공용량에서 차감 |
| 그 외 이용자 | 같은 분야의 공용량에서만 차감 |

- 점령 길드원도 전용량을 모두 사용한 뒤에는 공용량을 이용할 수 있다.
- 일반 이용자는 공용량이 소진되면 전용량이 남아 있어도 사용할 수 없다.
- 한 번의 길드원 생산 요청이 전용 잔량을 초과하면 전용 잔량을 먼저 사용하고 나머지만 공용에서 사용한다.
- 해당 이용자가 사용할 수 있는 잔량이 모두 소진되면 추가 생산은 불가능하다.
- 길드원 전용량은 길드원 개인별 할당이 아니라 해당 분야에서 점령 길드원들이 함께 사용하는 일일 총량이다.

예시: 약초 전용 잔량 3, 공용 잔량 7인 상태에서 점령 길드원이 5단위를 생산하면 전용 3과 공용 2를 차감한다. 처리 후 전용 잔량은 0, 공용 잔량은 5가 된다.

## 5. 일일 초기화

- 도시와 마을의 생산 가능량은 매일 한국시간 24:00, 즉 다음 날 00:00에 초기화한다.
- 도시의 농업·약초 공용량과 길드원 전용량도 같은 시각에 각각 초기화한다.
- 사용하지 않은 생산 가능량은 다음 날로 이월하지 않는다.
- 초기화 대상은 생산 가능량이며 이미 획득한 재료·제작물은 제거하지 않는다.
- 마을의 주간 농업·약초 유형은 일일 초기화로 바뀌지 않는다.

## 6. 제작 장소

- 제작은 도시·마을의 위치나 해당 마을의 주간 생산 유형과 관계없이 어디서든 가능하다.
- 마을 유형은 채집·재배 가능 분야에만 영향을 준다.
- 이번 합의로 새로운 제작세, 거래세, 제작 보너스나 수확 보너스를 추가하지 않는다.
- 기존 제작 재료·비용·숙련도 규칙은 별도 변경 없이 유지한다.

## 7. 후속 구현 검증 기준

아래는 이번 문서 커밋에서 구현·실행한 테스트 목록이 아니라 실제 구현 시 충족해야 할 기준이다.

- 지도와 서버의 유효 거점 목록은 도시 1개·마을 4개로 일치한다. 기존 위치·점령 데이터의 이전 방안을 마련한다.
- 주간 마을 유형은 서버의 실제 점령 길드 권한에 따라 선택한다. 화면의 예시 소유자 정보나 클라이언트 전달 길드 ID를 권한 근거로 삼지 않는다.
- 생산 요청 시 현재 도시 점령 길드와 요청자의 유효한 길드원 자격을 서버에서 확인한다.
- 길드원 요청은 전용 우선·공용 차순위로 원자적으로 차감하며, 동시 생산으로 잔량이 음수가 되거나 같은 생산량을 중복 지급하지 않는다.
- 일반 이용자는 어떤 경우에도 전용 잔량을 사용할 수 없다.
- 농업 생산이 약초 잔량을 차감하거나 반대로 약초 생산이 농업 잔량을 차감하지 않는다.
- 재시도·중복 요청은 한 번만 차감·지급한다.
- 한국시간 23:59:59와 다음 날 00:00:00 경계에서 새 날짜의 생산량을 정확히 적용한다.
- 실제 서버 응답으로 현재 날짜, 분야별 전체·공용·전용 잔량과 다음 초기화 시각을 표시한다.
- 거점이나 마을 유형이 달라도 유효한 제작 요청을 처리할 수 있다.
