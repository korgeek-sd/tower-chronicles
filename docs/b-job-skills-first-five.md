# B등급 직업 스킬 기획 — 1차 5종

확정일: 2026-10-05
상태: 사용자 승인 기획. B등급 액티브 스킬과 이미지 연결 구현 완료. 결투가는 기존 구현 유지.

## 공통 규칙

- 기존 전투 엔진의 직접 공격, 다중 타격, 회복, 출혈, 상태이상 제거, 공격 피해 증가, 받는 피해 감소, 전투 자원만 조합한다.
- 새로운 표식, 자원 종류, 발동 조건이나 전투 규칙을 추가하지 않는다.
- 선봉 탐사자·추적자·생환가·탐사 의무관은 전투 자원 0 시작, 최대 4칸을 사용한다.
- 결투가는 기존 무자원 스킬 구성을 유지한다.
- 신규 수치는 승인된 기획값이며 구현 시 기존 엔진으로 동작을 검증한다.

## 구현과 이미지 제작 기준

- 출혈 화살은 기존 출혈 효과의 지속시간과 턴당 피해 설정을 그대로 사용한다.
- 추적 표식, 적 HP 70% 이상 조건, 공격력 비례 회복은 사용하지 않는다.
- 결투가 스킬 ID는 기존 duelist_skill_1, duelist_skill_2, duelist_skill_3을 유지한다. 신규 직업의 스킬 ID는 실제 등록 시 확정한다.
- 역할: 선봉 탐사자=공격·방어 강화, 추적자=출혈·연속 공격, 생환가=회복·피해 감소, 결투가=반격·마무리, 탐사 의무관=치료·상태이상 제거.
- 이미지 제작에는 저장소의 스킬 이미지 생성 규칙을 사용한다. 굵은 픽셀, 제한된 색상, 큰 화면 점유율, 투명 배경을 유지한다.
