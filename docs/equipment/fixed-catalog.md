# 고정 장비 규칙

장비 9종 × 5등급 = 45개 상품. 강화·랜덤 옵션·수치 편차 없음. 거래소 상품 키는 `equipment:<kind>:<grade>`. 인스턴스 ID는 소유권과 장착에만 사용한다. 기존 저장 형식의 enhancement는 호환을 위해 0으로 유지하고 계산·표시·상품 분류에 사용하지 않는다.

모든 수치는 캐릭터 기본 능력치에 더해지는 고정 값이다. 확률·배율 수치는 %p 증가로 표시한다. 기본 전투 능력치는 HP 180, 공격력 8, 방어력 3, 치명타 확률 5%, 치명타 피해 150%, 방어 관통 0%.
