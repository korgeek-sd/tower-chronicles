# 탑의 기록 v0.1.24

《탑의 기록》(Tower Chronicles)은 네 개의 고대 탑을 중심으로 성장한 자유상업도시 노바르를 배경으로 하는 모바일 세로형 다크 판타지 수동 턴제 RPG 프로토타입입니다.

- 앱 버전: `0.1.24`
- 저장 스키마: `v17`
- 기술: React 19, TypeScript, Vite
- 저장: 브라우저 `localStorage`
- 현재 완성 콘텐츠: 철맥의 첨탑 1~10층

세계관과 시각 방향은 `WORLD-AND-ART-DIRECTION.md`를 기준으로 합니다.

## v0.1.24 원정 이벤트

전투 사이 선택형 이벤트, 보스 진행도 소비·반복 조우, 생환 확정과 이벤트 저장/복귀를 연결했습니다. 일반 정식 이벤트 목록은 비워 두고 샘플 5종을 테스트 모드로 격리했습니다. `event-preview.html`로 저장 데이터 없이 바로 화면을 확인할 수 있습니다. 실제 원정 테스트는 `play.html?events=test`에서 새 원정을 시작하세요. 상세 구현·검증·콘텐츠 추가 방법은 `EVENTS-v0.1.24.md`를 참고하세요.

## 바로 실행

빌드가 끝난 `play.html`을 Chrome 또는 Edge로 열면 됩니다. JavaScript와 CSS는 HTML에 포함되어 있고 이미지는 같은 위치의 `assets` 폴더를 참조합니다.

브라우저가 `file://` 실행이나 저장을 제한하면 개발 서버를 사용하세요.

```sh
npm install
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다. 개발에는 Node.js 22 이상을 권장합니다.

## 첫 플레이 권장 순서

1. 철맥의 첨탑 1층 원정을 시작합니다.
2. 자동전투로 철광석을 6개 이상 모읍니다.
3. 안전 귀환하여 임시 전리품을 영구 보관함에 확정합니다.
4. 공방에서 T1 검을 제작하고 완료품을 수령합니다.
5. 장비 화면에서 제작한 검을 장착한 뒤 다시 원정합니다.

- 검, 단검, 활, 지팡이와 무기별 전투 성향

- 최근 체결가, 매수·매도 호가, 기간별 가격·거래량 통계

- 조합 금고, Silver 원장과 수익 분배율 데이터 구조
- 황금기록자 기간, 프리셋 확장, 제작 절감, Gold 판매 수수료 혜택

### 저장과 도구

- 저장 스키마 v1~v16을 v17로 순차 이전
- 주요 이전 단계에서 원본 저장을 별도 키에 한 번 백업
- 진행 중 원정의 HP, 적, 포션, 전리품, 턴과 장비 고정값 복구
- 지원 브라우저에서 WebMCP로 원정 상태 조회와 안전 귀환
- 단독 실행용 `play.html`과 정적 배포용 `dist`

## 실제 플레이 가능 범위

현재 탑 선택 화면에서 입장 가능한 콘텐츠는 철맥의 첨탑 1~10층입니다.

- 일반 몬스터: 고블린 광부, 동굴 쥐, 광산 박쥐, 고블린 운반꾼, 고블린 감독관
- 10층 보스: 광산 오우거
- 철맥, 붉은 송곳니, 수정탑은 T1~T5 배경 에셋이 연결되어 있습니다.
- 붉은 송곳니의 성소, 천광의 수정탑, 칼레온의 녹빛 첨탑 전투 콘텐츠는 준비 중입니다.
- 칼레온 배경, 플레이어 후면 캐릭터, 전용 스킬 일러스트도 준비 중입니다.

## 개발 명령

```sh
npm run typecheck
npm test
npm run build
node scripts/standalone.mjs
```

- `typecheck`: 파일을 생성하지 않는 TypeScript 검사
- `test`: 게임 엔진, 저장 이전, UI 계약을 포함한 204개 테스트
- `build`: `dist` 프로덕션 빌드 생성
- `standalone.mjs`: 현재 번들에서 루트 `play.html` 생성

- 테스트 182개 성공, 기존 실패 22개 (변경 전 31개 실패; EVENTS-v0.1.24.md 참고)
- TypeScript 검사 성공
- 테스트 실행 환경 Node.js 24.19.0

## 주요 구조

- `src/main.tsx`: 앱 상태와 전체 화면 연결
- `src/game/data`: 밸런스, 탑, 몬스터, 그래픽, 외형 데이터
- `src/game/engine`: 전투, 원정, 드롭, 제작, 숙련도, 프리셋
- `src/game/market`: 주문 체결, Gold 교환 기반, 시장 통계
- `src/game/association`: 조합 규칙과 상태 변경
- `src/storage/repository.ts`: 저장 검증, 백업, v1~v17 이전
- `src/components`: 전투, 인벤토리, 거래소, 조합 UI
- `public/assets`: 배경, 몬스터, 플레이어, 인벤토리·내비게이션 이미지
- `tests`: 자동 테스트
- `dist`: 정적 배포 결과
- `play.html`: 독립 실행본

## 알려진 제약

- 서버, DB, 로그인과 실제 다른 플레이어 연결은 없습니다.
- 거래소와 조합은 로컬 단일 사용자 프로토타입입니다.
- 결제, 광고, PvP, 랭킹, 채팅, 점령전은 없습니다.
- 장비 강화·파괴, 판매·분해·버리기는 아직 없습니다.
- 여러 브라우저 탭 사이의 실시간 저장 동기화와 충돌 처리는 없습니다.
- `localStorage`는 사용자가 수정할 수 있으므로 향후 온라인 경제의 권위 있는 데이터로 사용하면 안 됩니다.
- 전체 200개 층의 장기 밸런스와 콘텐츠는 아직 완성되지 않았습니다.
