# 탑의 기록 v0.1.43

《탑의 기록》(Tower Chronicles)은 네 개의 고대 탑을 중심으로 성장한 자유상업도시 노바르를 배경으로 하는 모바일 세로형 다크 판타지 수동 턴제 RPG 프로토타입입니다.

- 앱 버전: `0.1.43`
- 저장 스키마: `v22`
- 기술: React 19, TypeScript, Vite
- 저장: 브라우저 `localStorage`
- 현재 실제 플레이 가능 탑: `철맥의 첨탑`, `천광의 수정탑`
- 메인 저장 키: `tower-record-v1`

실제 동작이 문서와 충돌할 경우 production code와 자동 테스트가 우선입니다. 최신 개발 상태는 `GPT-HANDOFF-v0.1.43.md`를 확인합니다.

## v0.1.43 — 장비 강화 v1

공방에서 제작 장비를 최대 +3까지 강화할 수 있습니다. 강화는 확률형이며 성공, 유지, 1단계 하락, 파괴 결과를 가질 수 있습니다.

### 강화 확률

| 시도 | 성공 | 유지 | 1단계 하락 | 파괴 |
| --- | ---: | ---: | ---: | ---: |
| +0 → +1 | 50% | 50% | 0% | 0% |
| +1 → +2 | 35% | 40% | 20% | 5% |
| +2 → +3 | 20% | 35% | 30% | 15% |

공통 규칙:

- 강화 결과와 관계없이 Silver와 재료를 소모합니다.
- 하락은 정확히 1단계입니다.
- 파괴된 장비는 영구 삭제됩니다.
- 장착 중인 장비가 파괴되면 해당 슬롯은 자동으로 해제됩니다.
- 원정 중 강화는 불가능합니다.
- 지급용 `낡은 훈련용 검`은 강화할 수 없습니다.
- 보호권, 실패 스택, 천장, 복구, 계승, 랜덤 옵션은 v1에 없습니다.

### 비용 — provisional balance

T1 기준:

| 시도 | Silver | 재료 |
| --- | ---: | ---: |
| +0 → +1 | 100 | 4 |
| +1 → +2 | 250 | 8 |
| +2 → +3 | 600 | 16 |

T2~T5는 각각 ×2~×5의 선형 배수를 사용합니다. 상위 티어 콘텐츠가 실제 플레이 가능해질 때 재조정할 예정입니다.

강화 재료:

- 무기 → 동일 티어 철광석
- 갑옷 / 신발 → 동일 티어 가죽
- 장신구 → 동일 티어 보석

### 강화 능력치

무기, 갑옷, 신발의 수치 기여도는 +1당 +0 성능의 10%씩 deterministic하게 증가합니다.

- +0: ×1.0
- +1: ×1.1
- +2: ×1.2
- +3: ×1.3

같은 장비 종류, 같은 티어, 같은 강화 단계라면 item id와 관계없이 항상 같은 성능을 가집니다.

장신구는 고유 패시브의 효과량만 증가하고 발동 조건은 바뀌지 않습니다.

| 장신구 | +0 | +1 | +2 | +3 |
| --- | ---: | ---: | ---: | ---: |
| 흡혈 | 8% | 9% | 10% | 11% |
| 불굴 | 30% | 32% | 34% | 36% |
| 광전사 | 40% | 43% | 46% | 50% |

- 불굴: HP 35% 이하 조건 고정
- 광전사: HP 40% 이하 조건 고정
- 흡혈: 기존 post-shield 직접 HP 피해 기준

### 강화 UI

공방의 `장비 강화` 화면에서 다음을 확인할 수 있습니다.

- 현재 강화 단계와 다음 단계
- 현재 / 다음 능력치 또는 장신구 패시브
- 성공 / 유지 / 하락 / 파괴 확률
- 필요한 Silver와 동일 티어 재료
- 현재 보유량
- 파괴 위험 경고 및 확인

## 강화 장비 호환

강화 단계는 기존 `Item.enhancement` 필드를 그대로 사용하므로 저장 스키마는 v22를 유지합니다.

강화 장비는:

- 인벤토리
- 장비 화면
- 전투 능력치
- 거래소 개별 장비 escrow
- 거래소 주문 취소 / 체결
- JSON 저장 / 불러오기

사이에서 동일한 종류, 티어, 강화 단계를 유지합니다.

거래소에 예치되어 인벤토리에서 빠진 장비도 `Tn 장비 +강화` 이름과 강화 metadata를 유지합니다.

## v0.1.42 기반 기능

### 전투 가독성

전투 화면에서 확정 Charge/Reactive 준비 행동, 보호막, 상태효과, 중첩, 남은 턴, 몬스터 스킬과 쿨다운을 확인할 수 있습니다. AI의 미래 행동을 임의로 예측하지 않고 실제 준비된 행동만 경고합니다.

### 탐사 생물록

현재 active catalog는 총 45종입니다.

- 철맥의 첨탑: 10종
- 붉은 송곳니의 성소: 10종
- 천광의 수정탑: 25종
- 칼레온의 녹빛 첨탑: 아직 active 개체 없음

일반 개체는 조우 → 1회 처치 → 3회 처치 순서로 정보가 해금되고, 보스는 1회 처치 시 전체 정보가 공개됩니다.

## 저장

현재 저장 스키마는 `v22`입니다.

v0.1.43은 새 persisted field를 추가하지 않습니다. 기존 `Item.enhancement: 0|1|2|3`를 실제 시스템으로 연결했으므로 v22 → v23 migration은 없습니다.
