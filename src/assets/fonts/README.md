# DOS fonts used in Tower Chronicles hunting

글꼴(폰트)로 도스고딕체·도스명조체(이담허 / leedheo 제작)를 사용하였습니다.

Source: https://github.com/hurss/fonts (master, downloaded 2026-10-13).
Originals: `ttf/DOSGothic.ttf` and `ttf/DOSMyungjo.ttf`.
Copyright (c) 2016-2022 Damheo Lee (이담허).
The original MIT license is preserved in `LICENSE.txt` alongside these fonts.

These WOFF2 files were generated with fontTools and Brotli from the original
TTF files, retaining the original font names and available characters in:
U+0020–00FF, U+1100–11FF, U+2000–27FF, U+3000–31FF,
U+AC00–D7A3 and U+FF00–FFEF. All 11,172 modern Hangul syllables are retained.
Other characters use the CSS fallback font. The original outlines are unchanged.

The fonts are self-hosted and applied only within `.tc-hunt`.
